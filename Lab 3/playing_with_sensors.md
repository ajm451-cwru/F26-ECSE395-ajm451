Like lab 2, I will be uploading my code to the Feather via the PlatformIO IDE extension in Visual Studio Code. I am using a Windows 11 laptop.

## Directory

* potentiometer.cpp - Prints the raw analog input to the Feather, received from the center terminal of a potentiometer whose side terminals are connected to ground and the supply +3.3 volts.

* voltage.cpp - Same as potentiometer.cpp, but it converts the raw reading to a floating point number representing the voltage at the input pin.

* touch.cpp - When a touch sensor is connected, the built-in LED will light when the sensor is touched. In addition, the serial register is updated every 20ms with a string saying whether the touch sensor is currently actuated.
