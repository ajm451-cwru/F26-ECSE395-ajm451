# Lab 2 - ESP32 Basics
**Andrew Manteau**

This is the first assignment working with the ESP32. In this assignment, I will make a blinking LED.

I am uploading the code to the ESP32 using the PlatformIO IDE extension in Visual Studio Code.

## Steps

1. Create and write the above content into esp32_basics.md

2. Download and install the PlatformIO IDE extension in VS Code.
3. Create a new project in the extension's menu.
4. Copy the provided skeleton code into main.cpp
5. Edit to code to insert the baud rate, print a custom message to the serial register, and define a pattern for LED blinking.
5. Plug in the Adafruit Feather using a USB-C cable.
6. Build the code using the checkmark button.
7. Upload the code to the device.
8. Monitor the LED and the terminal output from reading the serial register.
9. Notice that the terminal is outputting garbage text and define the monitor speed in platformio.ini to be identical to the baud rate.
10. Re-upload the code, notice that the terminal is reading the custom message properly.
11. Take a video of the LED blinking and the terminal displaying the proper output.
